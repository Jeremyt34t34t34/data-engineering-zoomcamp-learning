# Data Engineering Zoomcamp Homework

This repository contains my public homework submissions for DataTalksClub Data Engineering Zoomcamp.

## Structure

```text
homework-submissions/
├── module-01-docker-terraform/
├── module-02-workflow-orchestration/
├── module-03-data-warehouse/
└── module-04-analytics-engineering/
```

Each module folder includes:

- `README.md` with answers and notes
- SQL, YAML, Python, or dbt files used to solve the homework
- Screenshots only when needed by the homework form

## Safety Notes

Do not commit cloud credentials, service account JSON files, `.env` files, Terraform state, dbt targets, logs, or full downloaded datasets.

The `.gitignore` in this folder is intentionally strict to avoid publishing secrets or large local artifacts.
